# Changelog

## 0.1.0

First release.

- Python package `applywright`: SQLite job store, triage, application package drafting, rendering, and promotion, apply bundle builder, and an MCP server for Claude Code.
- Chrome MV3 extension: form fillers for Greenhouse, Lever, and Ashby that never submit, a submission record, a LinkedIn single-job capture, and an optional JobCopilot export.
- Evidence-locked resumes and cover letters. Every claim cites an ID from the user's own evidence catalog.
- The toolkit never submits an application and never answers legal questions.
